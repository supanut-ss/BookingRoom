# BookingRoom Web (React JS)

This frontend uses React JS with `react-scripts` (Create React App style).

## Available Scripts

### `npm start`

Runs the app in development mode on `http://localhost:3000`.

### `npm run build`

Builds the app for production to the `build` folder.

## Environment Variable

Create `.env` from `.env.example` and set:

`REACT_APP_API_BASE_URL=http://localhost:5224`
